## 🎯 Étapes pour Soumettre à Google Search Console

### Étape 1: Accéder à Google Search Console
1. Allez sur [Google Search Console](https://search.google.com/search-console)
2. Connectez-vous avec votre compte Google (celui qui a accès au site)
3. Sélectionnez votre propriété : `https://dpai-strategy.com/`

### Étape 2: Vérifier le Sitemap
1. Dans le menu de gauche, cliquez sur **"Sitemaps"** (ou **"Index"** > **"Sitemaps"**)
2. Vérifiez si un sitemap existe déjà
3. Si oui, supprimez-le pour le resoumettre

### Étape 3: Soumettre le Nouveau Sitemap
1. Dans le champ **"Ajouter un nouveau sitemap"**, entrez :
   ```
   sitemap.xml
   ```
2. Cliquez sur **"Soumettre"**
3. Google va commencer à analyser votre sitemap

### Étape 4: Vérifier l'Indexation
1. Allez dans **"Index"** > **"Couverture"**
2. Attendez 24-48h pour que Google analyse les nouvelles pages
3. Vérifiez que les 3 nouvelles pages apparaissent comme **"Valide"**

### Étape 5: Inspecter les URLs Individuellement
Pour chaque nouvelle page, faites :
1. Allez dans **"URL"** > **"Inspection"**
2. Entrez l'URL complète :
   - `https://dpai-strategy.com/croissance-externe.html`
   - `https://dpai-strategy.com/outil-ma.html`
   - `https://dpai-strategy.com/logiciel-fusion-acquisition.html`
3. Cliquez sur **"Tester l'URL en direct"**
4. Si tout est bon, cliquez sur **"Demander une indexation"**
