## Vérifications à Effectuer

### Après Déploiement
- [ ] Soumettre le sitemap à Google Search Console
- [ ] Vérifier l'indexation dans Google Search Console
- [ ] Tester avec l'outil d'inspection d'URL de Google
- [ ] Vérifier avec Bing Webmaster Tools
- [ ] Tester le responsive design sur mobile

### Tests Techniques
- [ ] Validation W3C HTML
- [ ] Validation CSS
- [ ] Test de vitesse (PageSpeed Insights)
- [ ] Test mobile-friendly (Google)
- [ ] Vérification des liens brisés

### SEO On-Page
- [ ] Vérifier la densité des mots-clés (2-3%)
- [ ] Vérifier la longueur des articles (>1000 mots recommandé)
- [ ] Vérifier les balises alt des images
- [ ] Vérifier les liens internes
- [ ] Vérifier les liens externes

## Outils Recommandés

1. **Google Search Console** - Suivi de l'indexation
2. **Google Analytics** - Analyse du trafic
3. **PageSpeed Insights** - Optimisation de la vitesse
4. **Mobile-Friendly Test** - Test mobile
5. **W3C Validator** - Validation du code
6. **Screaming Frog** - Audit SEO technique
7. **Ahrefs / SEMrush** - Analyse concurrentielle
8. **Yoast SEO** (si WordPress) - Optimisation on-page
